# Portfolio Clone (Adobe-style)

사용자가 제공한 레퍼런스 레이아웃을 기반으로, 이력/포트폴리오 내용을 반영한 정적 포트폴리오 템플릿입니다.

## 실행 방법

```bash
cd portfolio-clone
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 포함 기능

- 좌측 고정 사이드바 + 모바일 햄버거 메뉴
- 프로젝트 텍스트 + 대형 이미지 모듈 나열
- 이미지 라이트박스(이전/다음/닫기, 키보드 제어)
- Back-to-top 버튼
- 이력서/포트폴리오 기반 요약 섹션
